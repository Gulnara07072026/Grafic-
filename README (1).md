# График отпусков

Страница для расчёта ежегодных оплачиваемых отпусков сотрудников на 2027 год (АО «Казахтелеком»).

## Что делает

- делит отпуск (30 календарных дней) на две части, первая часть не меньше 14 дней;
- добавляет экологические дни сотрудникам, родившимся до 1990 года;
- раскладывает части отпусков по году равномерно, с лимитом одновременно отсутствующих;
- не включает праздничные дни в число дней отпуска (сдвигает конец периода);
- показывает годовой график, итоги по сотрудникам и проверки;
- выгружает график в CSV.

Все правила (количество дней, год, эко-дни, лимит, список праздников) меняются на самой странице в блоке «Правила расчёта».

## Как выложить на GitHub

1. Откройте https://github.com и войдите в аккаунт.
2. Нажмите **+** в правом верхнем углу, затем **New repository**.
3. В поле **Repository name** введите, например, `vacation-schedule`. Выберите **Private**, если страница не должна быть публичной. Нажмите **Create repository**.
4. На странице нового репозитория нажмите ссылку **uploading an existing file**.
5. Перетащите в окно файлы `index.html` и `README.md`, затем нажмите **Commit changes**.

## Как включить открытие страницы по ссылке (GitHub Pages)

1. В репозитории откройте **Settings**, затем **Pages**.
2. В разделе **Build and deployment** в поле **Source** выберите **Deploy from a branch**.
3. В поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты вверху страницы появится ссылка вида `https://ваш-логин.github.io/vacation-schedule/`.

Для приватных репозиториев Pages доступны не на всех тарифах GitHub. Если пункта Pages нет, скачайте `index.html` и открывайте двойным щелчком в браузере.

## Где хранятся данные

Данные сохраняются в браузере (localStorage) на том компьютере, где их вводили. На другом компьютере или в другом браузере страница откроется с примером. Поэтому после ввода данных нажмите **Скачать CSV** и сохраните файл как резервную копию.

## Важно проверить

- число эко-дней (по умолчанию 7) зависит от зоны проживания, уточните в отделе кадров;
- праздники 2027 года и переносы выходных сверьте с постановлением Правительства РК, Курбан айт указан ориентировочно;
- деление отпуска на части оформляется по соглашению работника и работодателя (ст. 92 ТК РК).
